## 2. Подробное описание выполненных работ

### Лабораторная работа №1. HTML + CSS
* **Цель**: разработка статических страниц с семантической версткой и CSS-стилизацией таблиц.
* **Что сделано**:
  * Созданы две страницы: `prizes.html` (категория, дата вручения, размер гранта в SEK, количество лауреатов) и `laureats.html` (имя/название, дата рождения/основания, страна, число премий).
  * Использованы обязательные семантические теги: `<header>`, `<nav>`, `<main>`, `<footer>`.
  * Таблицы сверстаны с использованием тегов `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`.
  * В файле `style.css` реализованы: границы ячеек (`border`), отступы внутри ячеек (`padding: 12px 16px`), чередование цвета строк («зебра» через `tbody tr:nth-child(even)`), эффект подсветки при наведении (`hover`) и аккуратные бейджи категорий.
  * Страницы взаимно связаны гиперссылками через навигационное меню `<nav>`.

---

### Лабораторная работа №2. Реактивность
* **Цель**: переход на реактивный фреймворк, разработка переиспользуемого компонента таблицы и маршрутизация SPA.
* **Что сделано**:
  * Развернуто SPA-приложение на **Vue 3 + TypeScript + Vite**.
  * Спроектирован переиспользуемый компонент `DataTable.vue`. Он принимает в качестве параметров:
    * `columns: Column[]` — массив настроек колонок (ключ поля, заголовок, выравнивание, функция форматирования `formatter`).
    * `data: any[]` — массив отображаемых данных.
    * Поддерживает scoped-слоты (`#cell-[key]`) для гибкой кастомизации содержимого конкретных ячеек.
  * Настроен роутер `vue-router` с двумя клиентскими маршрутами (`/prizes` и `/laureates`), переключающими отображение страниц без перезагрузки браузера.

---

### Лабораторная работа №3. Стороннее API
* **Цель**: получение структурированных данных из внешнего API через Axios, внедрение пагинации и фильтрации.
* **Что сделано**:
  * Реализован единый базовый сервис `BaseApiService.ts`, инкапсулирующий работу с клиентом `Axios` (`axios.create`, общий `baseURL: 'https://api.nobelprize.org/v2.1'`, перехватчики запросов/ответов и централизованная обработка сетевых ошибок).
  * Созданы специализированные классы-сервисы `PrizesService` и `LaureatesService`, отправляющие запросы к официальному API Нобелевской премии.
  * Реализована **пагинация**: компонент `Pagination.vue` с выбором лимита (5, 10, 25 записей на странице), навигацией по страницам и счетчиком записей.
  * Реализована **фильтрация**:
    * На странице премий: фильтр по категории (физика, химия, медицина, литература, мир, экономика) и фильтр по году вручения.
    * На странице лауреатов: текстовый поиск по имени персоны или наименованию организации.

---

### Лабораторная работа №4. Строгая типизация
* **Цель**: проверка типов данных, поступающих от внешнего API во время выполнения (runtime validation), с помощью библиотек `io-ts` и `fp-ts`.
* **Что сделано**:
  * Разработана функция `decodeOrThrow(codec, data)`:
    * Запускает валидацию `codec.decode(data)`.
    * С помощью `fp-ts/lib/Either` (`E.isLeft`) проверяет корректность структуры данных.
    * В случае расхождения схемы формирует подробный лог через `PathReporter.report()` и выбрасывает исключение с точным указанием невалидных полей.
  * В файле `types/codecs.ts` созданы строгие io-ts кодеки:
    * `PrizesApiResponseCodec` (структура премии, переводы, массив лауреатов, пагинационные метаданные `meta`).
    * `LaureatesApiResponseCodec` (данные персон, даты, места рождения/основания, список присужденных премий).
    * Статические типы TypeScript автоматически выводятся через `t.TypeOf<typeof ...>`.
  * В `BaseApiService` внедрен метод `getValidated`, который декодирует ответы через переданный кодек до их передачи в компоненты.
  * В интерфейс добавлена кнопка **«Тест decodeOrThrow на сбой»**, демонстрирующая работу валидатора при получении искаженных данных.

---

### Лабораторная работа №5. Кеширование и PWA
* **Цель**: обеспечение надежной работы приложения при отсутствии интернет-соединения и фоновое обновление данных при его восстановлении.
* **Что сделано**:
  * Приложение переведено в формат **PWA** (Progressive Web App): сгенерирован Web App Manifest (`manifest.webmanifest`), заданы иконки, цвета темы и режим отображения `standalone`.
  * Внедрен плагин `vite-plugin-pwa` с библиотекой `Workbox`. Настроен Service Worker со стратегией кеширования `NetworkFirst` для запросов к API:
    * При наличии соединения приложение делает сетевой запрос и сохраняет результат в кеш.
    * При отсутствии сети или таймауте более 3 секунд ответ мгновенно извлекается из кеша.
  * Реализован реактивный хук `useNetworkStatus.ts`, слушающий события браузера `online` и `offline`.
  * В `App.vue` добавлен визуальный баннер статуса соединения:
    * В офлайн-режиме пользователя информируют о работе с закешированными данными.
    * При восстановлении соединения баннер сообщает об успехе, и приложение автоматически выполняет повторный запрос для синхронизации данных.
